프레임 관리

프레임은 가로 1800×1200px(6×4인치, 300dpi) PNG로 만들고, 사진이 들어갈 칸을 투명하게 비워 주세요. 투명한 칸을 자동으로 찾아서 왼쪽 위부터 순서대로 사진을 채워요.

    모든 기기에 적용하기

    모든 기기에서 쓸 프레임은 GitHub 저장소의 frames 폴더에 PNG를 올리면 1~2분 뒤 자동으로 반영돼요. 파일 이름이 프레임 이름이 되고, 이름 앞에 01_, 02_를 붙이면 그 순서대로 보여요. 위에서 올린 프레임은 이 기기에서만 쓰는 임시 프레임이에요.
